Exp6 query list and what each does:
1. GenderCount
- Simple count of students by gender.

2. LunchTypeCount
- Simple count of students by lunch type.

3. AvgScoresByGender
- Average math, reading, and writing grouped by gender.

4. AvgTotalByParentalEducation
- Average total score (math+reading+writing) grouped by parental education.

5. PerformanceBandDistribution
- Bands each student by average score:
  Excellent >= 80, Good >= 60, Average >= 40, else Poor.

6. TopNStudentsByTotalScore
- Complex top-5 extraction using descending key sort in MapReduce.

7. TestPrepImpact
- Compares average total score for completed vs none test-prep course.

8. HighestMathByRace
- Finds maximum math score inside each race/ethnicity group.

9. ScoreGapBucketCount
- Complex bucket analysis of reading-math gap:
  ReadingMuchHigher, ReadingHigher, Balanced, MathHigher, MathMuchHigher.

10. DistinctScoreTriplesCount
- Complex uniqueness query for distinct (math, reading, writing) score combinations.

8) If a new query is asked in exam/viva (proper workflow)
1. Create new Java file in src/, for example src/NewQuery.java.
2. Follow same structure:
  - Mapper parses CSV using CsvUtils.parseCsv(...)
  - Skip header using CsvUtils.isHeader(...)
  - Emit key/value as needed
  - Reducer computes final metric
  - In main(), set local mode:
    conf.set("mapreduce.framework.name", "local");
    conf.set("fs.defaultFS", "file:///");
3. Recompile all:
  javac -classpath "$(/home/vinayak/hadoop/bin/hadoop classpath --glob)" -d classes src/*.java
4. Recreate jar:
  jar -cvf exp6_hadoop.jar -C classes/ .
5. Run new class:
  rm -rf output/new_query_output
  /home/vinayak/hadoop/bin/hadoop jar exp6_hadoop.jar NewQuery data/StudentsPerformance.csv output/new_query_output
6. View result:
  cat output/new_query_output/part-r-00000
7. (Optional) Save proof:
  cat output/new_query_output/part-r-00000 > verification/new_query_output.txt
